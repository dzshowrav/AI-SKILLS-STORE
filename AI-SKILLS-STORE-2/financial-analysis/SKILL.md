# Skill: financial-analysis

## When to Use
Use when the user asks to analyze or review financial statements, typically provided as a PDF file.

## Procedure
1. Identify the source PDF document
2. Extract text content from the PDF
3. Parse key financial statements: balance sheet, income statement, cash flow statement
4. Perform year-over-year comparisons
5. Calculate key financial ratios (liquidity, profitability, leverage, efficiency)
6. Identify strengths, challenges, and strategic opportunities
7. Generate output documents (markdown, HTML, summary text)
8. Provide an executive summary
