# Awesome OpenTUI

Curated list of OpenTUI ecosystem projects. Reference for finding existing TUIs and libraries.

## Official Resources

- [OpenTUI](https://github.com/sst/opentui) — Main OpenTUI project
- [create-tui](https://github.com/msmps/create-tui) — Scaffold new OpenTUI apps
- [OpenCode](https://opencode.ai/) — AI coding agent for the terminal

## Developer Tools

- [cftop](https://github.com/NWBY/cftop) — Cloudflare Workers TUI
- [critique](https://github.com/remorses/critique) — Git changes review TUI
- [easiarr](https://github.com/muhammedaksam/easiarr) — Arr applications manager TUI
- [ghui](https://github.com/kitlangton/ghui) — GitHub PR manager TUI
- [hunk](https://github.com/modem-dev/hunk) — Terminal diff viewer for agentic coders
- [opendocker](https://github.com/flat6solutions/opendocker) — Docker container manager TUI
- [red](https://github.com/evertdespiegeleer/red-cli) — Redis TUI
- [tokscale](https://github.com/junhoyeo/tokscale) — Token usage tracker TUI
- [tuiboard](https://github.com/NazzarenoGiannelli/tuiboard) — Terminal kanban board with planner and agenda
- [waha-tui](https://github.com/muhammedaksam/waha-tui) — WhatsApp HTTP API TUI
- [restman](https://github.com/cadamsdev/restman) — REST API testing TUI
- [t-req](https://github.com/tensorix-labs/t-req) — .http file workspace browser TUI
- [termdraw](https://github.com/benvinegar/termdraw) — Terminal drawing editor for diagrams and UI mocks

## Libraries

- [anscribe](https://github.com/msmps/anscribe) — Capture live UI from OpenTUI apps for agents (clipboard/MCP)
- [opentui-spinner](https://github.com/msmps/opentui-spinner) — Spinner component for OpenTUI
- [opentui-skill](https://github.com/msmps/opentui-skill) — OpenTUI reference skill for OpenCode
- [opentui-ui](https://github.com/msmps/opentui-ui) — UI component library for @opentui/core

## Miscellaneous

- [gloomberb](https://github.com/vincelwt/gloomberb) — Financial terminal using OpenTUI
- [opentui-doom](https://github.com/muhammedaksam/opentui-doom) — Play DOOM in terminal via OpenTUI framebuffer
- [present-drop](https://github.com/msmps/present-drop) — Festive terminal game

## Starters & Examples

- [opentui-examples](https://github.com/msmps/opentui-examples) — Collection of example OpenTUI projects

## Testing & Automation

- [pilotty](https://github.com/msmps/pilotty) — Terminal automation for AI agents (like Vercel's agent-browser)
