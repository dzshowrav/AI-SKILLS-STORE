# Analyze Document

## Input Parameters

| Parameter | Required | Description |
|-----------|----------|-------------|
| document_source | Yes | File path, uploaded file, or direct text content |

## Procedure

1. If no document is provided, ask user to upload, provide path, or share text
2. Read the document using appropriate tools
3. Analyze structure, content, clarity, and relevance
4. Provide constructive, balanced feedback on strengths and areas for improvement
