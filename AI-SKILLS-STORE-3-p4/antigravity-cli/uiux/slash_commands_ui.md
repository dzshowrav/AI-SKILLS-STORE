# Slash Commands UI

---

## Command Palette

```
Ctrl+P ── Command Palette ─────────────────────────
│                                                     │
│  > /fea                                              │
│                                                     │
│  System Commands (3):                               │
│  ● /feature      Create new feature                 │
│  ● /feature:test Add tests to feature               │
│  ● /fetch        Fetch context                      │
│                                                     │
│  Skill Commands (2):                                │
│  ○ /skill:go      Go development helpers            │
│  ○ /skill:db      Database commands                 │
│                                                     │
│  Tip: Tab to autocomplete                           │
└─────────────────────────────────────────────────────┘
```

- Filtered by typed prefix
- System and skill commands separated
- Categories for organization
- Tab completion
